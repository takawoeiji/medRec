# medRec

紙の「会員登録表」と「入会同意書」を電子化した会員記録 Web アプリです。

## できること

- 会員の登録・編集・削除、一覧と検索（氏名・フリガナ・電話・住所、会員種別）
- 登録表の項目すべて（基本情報、連絡先、身長・血圧、断食前後の体重・体脂肪、該当項目のチェック、症状、施術後の感想、顔写真）
- 入会同意書（同意日、画面上での自署、代理人氏名・続柄）
- 紙と同じ体裁での表示と A4 印刷（1 枚目 登録表、2 枚目 同意書）
- バックアップ（JSON）の書き出し・取り込み、一覧の CSV 書き出し
- 団体名・登録表の題名・入会注意事項の本文は「設定・データ」で変更

## データの保存先

記録は **この端末のブラウザ内（IndexedDB）にだけ** 保存され、外部には送信されません。
端末間の共有はなく、ブラウザのデータを消去すると記録も消えます。「設定・データ」から定期的にバックアップを書き出してください。

## 開発

```bash
npm install
```

```bash
npm run dev
```

```bash
npm run build
```

`npm run build` の出力（`dist/`）は静的ファイルなので、任意の静的ホスティングに置けます。

## 構成

- React 18 + Vite + TypeScript（追加ライブラリなし）
- `src/types.ts` 会員データの型と登録表の項目定義
- `src/db.ts` IndexedDB への保存、バックアップ、CSV
- `src/components/` 一覧・登録フォーム・登録表（印刷）・設定・自署欄
